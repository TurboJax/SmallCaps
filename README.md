# SmallCaps!

Easy-to-use font to help convert regular text to the popular small caps font!  
To use small caps, set the font to `small_caps` or `minecraft:small_caps`.  
It replaces the normal unicode text of a-z and A-Z so you don't need to find the actual characters online.  

For Minimessage, the conversion is as simple as `<font:small_caps>Hello World!`  
In 1.20.2+, you are able to use non-text characters inside of a small caps font block.  If a letter is not a-z, it will fall back to the default font.  

Fun fact: This feature is available in 1.20, but overlays weren't a thing until 1.20.2.
